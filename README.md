# 🏠 Smart House Price Prediction System

An AI-powered web application that predicts house prices using Machine Learning algorithms and real-estate analytics. The platform helps users estimate property prices based on features like location, area, number of bedrooms, bathrooms, amenities, and more.
Live Demo:https://prop-insight-nova-2.onrender.com/

---

## 🚀 Features

- 🤖 AI-based House Price Prediction
- 📊 Interactive Dashboard & Data Visualization
- 📍 Location-based Price Analysis
- 🏡 Smart Property Recommendations
- 📈 Real-time Market Trend Insights
- 🔍 Advanced Property Search & Filters
- 📱 Fully Responsive Modern UI/UX
- 🌙 Dark/Light Mode Support
- ⚡ Fast and Scalable Architecture

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository
git clone https://github.com/A760-st/prop-insight-nova.git
cd smart-house-price-prediction

---

### 2️⃣ Frontend Setup

cd frontend
npm install
npm run dev

---

### 3️⃣ Backend Setup
cd backend
pip install -r requirements.txt
python app.py

## 🧠 Machine Learning Model

The project uses Regression Algorithms for prediction:

* Linear Regression
* Random Forest Regressor
* Decision Tree Regressor
* XGBoost Regressor

### Parameters Used

* Area (sq.ft)
* Number of Bedrooms
* Bathrooms
* Location
* Parking
* Furnishing Status
* Property Age
* Amenities

## 📊 Dataset

The dataset contains real-estate housing data with multiple pricing factors used for training and evaluation.

Example fields:

| Feature  | Description         |
| -------- | ------------------- |
| Area     | Total area in sq.ft |
| BHK      | Number of bedrooms  |
| Bathroom | Number of bathrooms |
| Location | Property location   |
| Price    | House price         |
